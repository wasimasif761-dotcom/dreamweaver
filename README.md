# Adobe Dreamweaver - Ambient Sound Mixer

> Ambient sounds to wash away distraction. High-quality procedural ambient audio mixer, sleep timer, and offline Progressive Web App (PWA).

## Features
- **10 Core Ambient Sounds**: Rain, Thunder, Waves, Wind, Fire, Birds, Crickets, Coffee Shop, Tibetan Singing Bowl, and White Noise.
- **Pure Web Audio API**: 100% client-side procedural synthesis with zero latency and no external server requirements.
- **Meander Mode**: Organic volume wandering that naturally breathes life into the soundscape.
- **Sleep Timer**: Smooth 45-second audio fade-out countdown timer.
- **Custom Mixes**: Save, recall, and manage custom ambient sound combinations in local storage.
- **100% Offline PWA**: Installable on Android, iOS, Windows, and macOS with full offline caching via Service Worker.
